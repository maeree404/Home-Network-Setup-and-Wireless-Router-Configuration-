# Home-Network-Setup-and-Wireless-Router-Configuration-
Cisco skills- hands-on lab activity

## Overview
This project involved configuring a simulated residential home network using Cisco Packet Tracer. The objective was to connect wired and wireless devices, configure a wireless router, implement basic network security and verify end-to-end connectivity.

## Tools Used
- Cisco Packet Tracer
- Cisco Wireless Router
- Cable Modem
- Ethernet and Coaxial Connections

## Network Configuration

### 1. Physical Connectivity
- Connected the cable splitter to the cable modem and television using coaxial cables.
- Connected the cable modem to the wireless router.
- Connected two desktop PCs to the router using Ethernet cables.

### 2. Router Configuration
- Accessed the router's administrative GUI through the Office PC.
- Configured DHCP to support a maximum of 10 clients.
- Changed the default router administrator password.

### 3. Wireless LAN Configuration
- Enabled the 2.4 GHz wireless network.
- Configured the SSID as `MyHome`.
- Enabled WPA2 Personal wireless security.
- Configured a wireless pre-shared key.

### 4. IP Addressing
- Configured the Office PC and Bedroom PC to obtain IP addresses through DHCP.
- Connected a laptop to the wireless network.
- Verified IP addressing and default gateway configuration.

## Connectivity Testing
- Tested wireless connectivity from the laptop.
- Verified internet access from the Office PC.
- Verified internet access from the Bedroom PC.
- Accessed `skillsforall.srv` through the simulated web browser.

## Skills Demonstrated
- Basic network infrastructure configuration
- IPv4 addressing and DHCP
- Wireless LAN configuration
- Router administration
- WPA2 wireless security
- Network connectivity troubleshooting
- End-to-end connectivity verification
